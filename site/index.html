INSTALLATION · 0.7.0

Guided setup
for each service.

First download and authenticate the installer with a trusted GitHub CLI in the same terminal. This sets MACT_INSTALLER_DIR for the commands below. Start with MACT Gateway. Enroll a separate worker for each Codex or Claude Code installation in the admin console, then run its setup on the machine where your projects live.

Read the installation guide →
1

Install MACT Gateway

Linux with systemd · run on your gateway server

sudo "$MACT_INSTALLER_DIR/install" setup gateway

Have your domain, Telegram bot token, and numeric Telegram user ID ready. The wizard guides HTTPS and passkey setup.

2

Connect a Codex worker

Linux with systemd or macOS · use your project account

"$MACT_INSTALLER_DIR/install" setup worker

Enter a worker name and a one-use enrollment URL from the admin console. Setup installs Codex if needed and guides account sign-in.

3

Connect a Claude Code worker

Linux with systemd or macOS · use your Claude account’s OS user

"$MACT_INSTALLER_DIR/install" setup claude-worker

First install Claude Code for the same OS user and check claude --version. Use an existing Claude login or configure an API key or auth token after enrollment. MACT installs the dedicated worker; it does not install or update the Claude CLI.

Use a separate enrollment URL for this worker. Set its model, endpoint, authentication, and tool permission mode in the admin console. Existing Codex workers keep their own configuration and state.

The trusted GitHub CLI verifies signed release provenance before the installer runs; the manager verifies downloaded binaries against authenticated checksums. Requires a preinstalled trusted GitHub CLI, curl and sha256sum or shasum; Codex runtime installation also uses tar and gzip. Enrollment URLs expire after 10 minutes. Linux setup offers service restrictions that block sudo by default. Follow the authenticated installation procedure before running these commands.

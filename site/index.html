Guided installation

Native Go binaries and embedded SQLite. No Python, Go compiler, or external database server required.

Authentication and access

The web interface supports passkeys and optional username/password sign-in. Telegram uses an allowlisted numeric user ID. Workers use enrollment credentials and configured workspace permissions.

Automatic updates

Automatic release checks and daily coding-agent runtime checks. Supported updates wait for idle workers before restarting.

INSTALLATION

Guided setup
for each service.

Start with MACT Gateway. Enroll a MACT Worker in the operations console, then run the worker installer on the machine where your projects live.

Read the installation guide →
1

Install MACT Gateway

Linux with systemd · run on your gateway server

curl -fsSL https://raw.githubusercontent.com/arizzi74/MACT/main/scripts/install.sh | sudo sh

Have your domain, Telegram bot token, and numeric Telegram user ID ready. The wizard guides HTTPS and passkey setup.

2

Connect a MACT Worker

Linux with systemd or macOS · use your project account

curl -fsSL https://raw.githubusercontent.com/arizzi74/MACT/main/scripts/install.sh | sh

Enter a worker name and the one-use enrollment URL from the admin console; the URL is visible as you paste it. On Linux, choose whether to restrict the service: yes (default) blocks sudo; no uses existing account permissions. The URL expires after 10 minutes. Setup retrieves connection settings, installs the supported coding-agent runtime if needed, and guides sign-in.

Requires curl and sha256sum or shasum. Runtime installation also uses tar and gzip. Review the installer source before running.

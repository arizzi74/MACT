# v0.6.33

Includes the Web UI tool previews and syntax highlighting described in
[v0.6.32](v0.6.32.md), with a correction for gateway update compatibility.

- Whisper reports the project release version required by existing gateway
  updaters. Its compiled binary cache includes that version; Piper and Qwen
  retain their reusable source-based caches.
- Native Whisper jobs verify the embedded version, and packaging executes the
  gateway, manager aliases, and bundled Whisper to check their versions before
  publication. Regression coverage rejects incompatible helper versions.

The v0.6.32 candidate passed integrity and signature checks but its bundled
Whisper source version was rejected by installed gateway updaters. The rejected
deployment kept the running gateway unchanged. This release restores the
existing updater contract.

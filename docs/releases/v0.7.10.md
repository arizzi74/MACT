# v0.7.10

Restore a single `curl` command for default gateway, Codex worker and Claude Code
worker setup, without requiring a preinstalled GitHub CLI. The README, website
and worker enrollment instructions provide those commands directly. The installed
v0.7.10 manager also prints the matching worker enrollment command when gateway
setup is completed.

The HTTPS-delivered bootstrap checks a native manager against reviewed SHA-256
pins for all four supported platforms before execution. That manager installs the
latest stable target release after authenticating its signed manifest and
downloaded packages. The bootstrap script itself remains the initial
HTTPS trust root. The separately authenticated first-install procedure using a
trusted GitHub CLI remains available as an optional advanced path.

Validation is limited to installation: bootstrap and documented authenticated-first
regressions, worker enrollment instructions, gateway completion guidance, shell
syntax, and an independent comparison of all four production pins with the
published v0.7.9 manifest.

The manual release workflow can select installer-only validation after proving
that the diff from the latest published stable release contains only the reviewed
installer files. Security scans, package audits, signing and publication checks
remain required. Normal release runs keep the full test suites.

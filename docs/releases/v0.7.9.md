# v0.7.9

This release delivers the security changes prepared for v0.7.8, whose
publication stopped during a GitHub asset-upload timeout.

- Report canceled worker database transactions consistently when cancellation
  races with SQLite rollback, while preserving successful commits and unrelated
  callback or SQL errors.
- Retry transient release uploads in bounded attempts, verify existing assets
  before reuse, and resume only a draft explicitly owned by the exact release
  repository, tag and commit. Published or mismatched releases remain protected.
- Authenticate the first native installer with an independently trusted GitHub
  CLI before execution. Installation instructions no longer execute a mutable
  downloaded shell script. Initial installation now requires a current `gh`
  supporting the documented attestation identity and source-ref checks. Existing
  native updates retain their own Sigstore verification.
- Bound Markdown parsing and DOM construction. Very large or dense messages
  display as complete inert text, with no actionable Markdown links.
- Expand default conversational credential redaction, preserve custom rules and
  literal credential rotation, and protect MACT/Claude configuration and state
  directories from raw file reads and browser uploads. Existing `.env` download
  restrictions remain. Custom installations should keep worker state in its own
  directory rather than at the project root.
- Require HTTPS for saved Claude API endpoints, including on persisted reads.
  Previously saved HTTP endpoints must be changed to trusted HTTPS before
  restarting an upgraded worker. MACT credit-balance requests reject redirects.
- Remove update-abort tokens from subprocess arguments. Automatic maintenance
  uses the existing private worker socket, including with older workers; manual
  `update abort` commands accept `--token-stdin` instead of `--token TOKEN`.
- Use rolling authentication/request limits, reject nonpositive Telegram update
  IDs, and bound optional session lookups on public shell pages.
- Ship patched Mermaid, DOMPurify, KaTeX and js-yaml code with reproducible
  notices and package inventory. Add full-history/current-tree secret scanning
  and advisory checks for both the npm lockfile and code bundled into production
  assets to CI and release gates.

No database migration is required. See [the remediation record](../security-remediation.md),
[worker boundaries](../security-boundaries.md), [browser verification](../browser-security.md)
and [authenticated installation](../installation.md#download-and-authenticate-the-installer)
for compatibility details and retained trust assumptions.

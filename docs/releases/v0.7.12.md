# v0.7.12

Collapsed workers in the Web UI now reflect the activity of their sessions:
green for running work and yellow when an answer is needed. Questions take
priority when a worker has both kinds of activity. A small count immediately
before the total shows how many sessions are active, counting each running or
waiting session once. Colours and counts update live; searching applies the
same filter to both counts.

Claude runtime maintenance no longer treats the presence of JSON managed
settings as an update prohibition. MACT evaluates the native update channel,
version bounds and update-disable settings while preserving unrelated model,
tool and permission policies. It respects managed-source precedence and reads
the last native remote-policy cache without changing policy or credentials.
Claude Code still refreshes and enforces its own startup policy. Ambiguous or
unsupported policy sources continue to require administrator-controlled updates.

Validation includes managed-policy precedence, version constraints, update
opt-outs, provider routing and file safety, plus responsive sidebar tests for
activity priority, live counts and saved collapse preferences. The new policy
reader also passed a read-only update check inside the affected Raspberry Pi
container with its managed settings unchanged.

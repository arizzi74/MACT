# v0.7.13

Model-capacity failures in the Web UI now show their error alongside a
30-second countdown and Cancel button. Leaving the countdown running queues
one **Continue** prompt for the affected session. Cancel dismisses the failure
without sending a prompt. A shared gateway deadline prevents multiple tabs,
reconnects or repeated failure reports from creating duplicate continuations.
Switching sessions preserves the deadline and unsent drafts. New input, pending
questions and runtime changes supersede the old retry. Other errors and the
runtime's own in-turn retries retain their existing behaviour.

Claude workers now use Claude Code's model, effort and permission labels,
including **Auto**, **Extra high**, **Accept edits** and **Bypass permissions**
where supported. **/effort** uses native supported values; **/reasoning** remains
an alias. **/usage** reports account usage. Official signed-in accounts read
Claude Code's native usage and API spending budget without submitting a model
prompt or requiring an administrator API key. Remaining account budget, session
cost and provider credits are shown separately, with unknown values left
unknown. An administrator budget API remains available as an optional fallback.

Validation covers countdown controls, cancellation and deadline races, shared
views, session navigation, responsive layouts, native usage projections and
account-switch isolation. A read-only probe also verified the native budget
reader against the Raspberry Pi's installed Claude Code runtime.

# v0.6.18

Large Web UI uploads now have enough time for validation and delivery on slower or busy gateway hosts. The relay send deadline is 30 seconds; a full 10 MiB attachment could previously exhaust the 10-second deadline during JSON processing and show a delivery error.

The maximum file size remains 10 MiB. Authentication, target checks, byte limits, and the worker socket's separate write deadline still apply. Upload test failures now include bounded frame diagnostics to identify transport errors without logging file contents.

The maximum-size authenticated transport test reproduced the failure with CPU contention and passed with this correction. Update the gateway and refresh the Web UI; workers follow the same release through their normal idle update process.

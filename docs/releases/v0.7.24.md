# v0.7.24

Fix WebUI answers to live questions and approval requests for Claude Code and
Codex. Replies now use the worker's recorded answer path, so the original
Telegram question is replaced with its answer and its buttons are removed.
Tool approvals are cleared through the same existing synchronization path.

Confirmed question answers appear as user messages in the WebUI and survive
reconnection. Failed submissions keep their drafts without displaying a false
success. Answer history stays scoped to its session, hides secret fields, and
loads independently of the native conversation. A guarded operator repair can
recover an already acknowledged historical reply without prompting the agent
again or interrupting its current turn.

Validation covers two-question live replies, restored requests, retry handling,
history, session isolation, secret masking, and Telegram edits. Unchanged audio
features are excluded from the scoped release checks.

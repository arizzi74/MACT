# v0.7.19

Claude account usage and budgets now refresh on a shared schedule with backoff.
HTTP `Retry-After` deadlines are honored, including deadlines longer than the
normal backoff cap. Failed or empty reads retain the previous budget and its
original check time, with a last-known label and next-refresh time.

Usage reads reuse a loaded Claude session's native cache and cooldowns when
possible. Timed-out account reads cannot stop its active turn. Account changes
clear old observations and schedules.

Validation is scoped to account polling, read-only native controls, and the
desktop/mobile usage status display. Voice and unrelated feature tests are
excluded; release packaging, security, audits and signed provenance remain
required.

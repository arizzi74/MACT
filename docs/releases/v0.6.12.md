# v0.6.12

The Web UI now has a session editor on desktop and mobile. Its pencil button
opens title-only renaming, permanent session deletion, or archive controls.
Renaming leaves the project directory untouched and updates the session title
in the gateway and Telegram views.

Archival saves the native resumable conversation and project together in a
checksummed `.tar.xz` under the worker service user's `~/CODEX_Archived`.
Optional project deletion is off by default and requires a verified backup,
native resume verification, idle/shared-directory checks and a final comparison
against the source files. A cleanup failure keeps the archive and reports a
warning.

The worker's **＋** dialog can restore an archived session to its original path
without overwriting changed projects or native sessions. Archive and restore
jobs persist across worker restarts. Browser reconnects observe the original
request rather than submitting destructive actions again. Archive imports
validate file paths, checksums, native namespaces and per-thread state.

This initial archive format supports Codex 0.163.0. Verification includes real
native legacy and paginated/forked sessions, source removal, process restarts
and continued turns against a local mock provider, without account credentials
or paid API calls. See the [Web UI guide](../webui.md#session-editing-and-archives)
for worker paths, safeguards and restoration behavior.

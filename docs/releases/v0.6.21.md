# v0.6.21

Introduces **MACT — Multi Agent Control Tower**, the new name for Codex Telegram
Gateway. MACT is a control hub for coding agents across sessions and machines;
Codex remains the currently supported runtime.

The browser interface, operations console, installed web app, website,
notifications and installer use the new branding. The `mact` management command
is added alongside the supported `codex-telegramgw` command. Both manage the
same installation. An unrelated program already using the new command path is
preserved and the installer reports how to use the compatibility command.

This release prepares installed updaters for the planned official GitHub
repository rename to `arizzi74/MACT`. Repository transition handling keeps strict
asset and release provenance verification, preserves historical release signing
identities and leaves custom repository selections independent.

After the repository move, fresh installations require v0.6.21 or later. Older
release files remain available and verifiable, but their bundled updaters cannot
follow the new repository name. The installer reports this before making changes.

Existing service names, configuration and database paths, worker credentials,
session history, bot bindings, project and archive directories remain intact.
The gateway hostname, `/tgw/` URLs and installed web app identity are preserved.
Worker binary updates continue to wait for idle.

See the [MACT migration guide](../mact-migration.md) for rollout order and recovery
of installations that miss the compatibility release.

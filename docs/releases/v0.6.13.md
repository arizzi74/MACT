# v0.6.13

Fixes project archival for saved sessions that are not currently loaded in
Codex. The worker previously called a terminal API that only accepts loaded
threads, then reported the resulting error as pending work. It now checks
terminals using each runtime's complete loaded inventory and requires a fresh
unloaded, idle state for sessions outside that inventory. Queue, goal, active
turn and project safeguards remain in place.

The session editor's pending-work message also covers unverified runtime state.
On narrow mobile screens, its four action buttons use two rows so labels stay
readable.

Regression coverage includes unloaded selected sessions and descendants,
multiple runtimes, loaded terminals and unexpected state transitions. The
official Codex 0.163.0 integration proof now exercises archive, optional project
removal and restoration for loaded and unloaded legacy and paginated sessions
in isolated test directories.

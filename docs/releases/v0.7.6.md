# v0.7.6

- Fix downloads and incoming file uploads on sandboxed Linux workers whose
  AppArmor profile allows project access but prevents reading the filesystem
  root. Traverse ancestor directories without requesting their listing, while
  retaining workspace boundaries, symlink rejection, and upload durability.
- Use the supported macOS 26 ARM runner for native audio builds after repeated
  macOS 15 runner capacity failures. Keep native smoke tests, package validation,
  and signed release verification for every supported platform.
- Include Codex 0.165.0 archive support with exact native database validation and
  isolated restoration checks. Archives require their original Codex version;
  failed checks preserve the project and any existing archive.
- Configure each Codex worker's default model, reasoning effort, and permissions
  for new sessions and session clears from the Operations console.
- Preserve newly created empty sessions after worker restarts and prevent
  answered multiline asynchronous questions from reappearing.

Gateway and worker updates use verified release artifacts. Workers wait until
active work and pending requests have finished before restarting.

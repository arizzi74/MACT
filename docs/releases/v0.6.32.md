# v0.6.32

This candidate is withdrawn from stable gateway updates. Its bundled Whisper
source version is incompatible with existing gateway updaters. Use the corrected
[v0.6.33](v0.6.33.md) release, which includes the changes below.

Tool execution in the Web UI is easier to follow on desktop and mobile.

- Running commands keep their detailed preview and show syntax highlighting,
  including embedded Python and JavaScript heredocs, without opening the tool.
- Completed tools collapse once to a single line with an outcome badge. Tools
  without a confirmed result retain a neutral completion label.
- Expanding a tool shows its complete available command, arguments, and result,
  including native dynamic-tool results. Manual expansion choices survive
  subsequent updates, and timestamps remain available in expanded entries.
- Tool bodies load when opened. Large results remain readable as plain text when
  they exceed the highlighting limit. Rendering uses text nodes rather than
  executing command or result markup.
- Late history and item events preserve newer tool state. Interrupted tools keep
  their outcome after a late sparse completion, and collapsing tools preserves
  the reader's position without interfering with older-history paging.

Browser regressions cover desktop and narrow mobile layouts, enlarged text,
keyboard disclosure, source and result retention, malicious markup, running
preview highlighting, outcome handling, and history races.

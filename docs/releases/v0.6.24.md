# v0.6.24

This candidate was not published. Browser validation exposed a timing issue in
the mobile dialog-focus test; [v0.6.25](v0.6.25.md) contains the corrected check.

Improves browser and installed-app sign-in, navigation and session controls.

- Passkey sign-in offers an optional **Trust this device for 30 days** choice
  and a device name. Trust has a fixed deadline; ordinary and password logins
  still last eight hours. Sensitive operations retain their recent-verification
  requirement.
- The admin console identifies browser/app logins by name, device ID, browser,
  activity and expiry, and supports revoking an individual device. Passkey
  reauthentication preserves its original trust deadline unless renewal is
  explicitly requested.
- **Log out** below **Settings** asks for confirmation, ends the current
  browser/app login and device trust, and clears unsent local drafts and
  attachments. Running sessions continue. Cancellation preserves the current
  view and draft; failed logout requests can be retried.
- **Open operations console** stays inside the installed web app at
  `/tgw/webui/admin/`, sharing its login. The existing `/tgw/admin/` address
  remains available, and installed app identity and scope remain unchanged.
- Native Codex retry notices clear when public model output resumes. Session
  renames refresh the connection label, and file links tolerate surrounding
  whitespace while retaining download validation.
- Builds require Go **1.26.10** or newer, including the standard-library
  certificate-trust security fix for
  [GO-2026-6809](https://pkg.go.dev/vuln/GO-2026-6809).

The database migration preserves existing browser logins as ordinary sessions;
30-day trust requires an explicit passkey choice. Existing workers, coding-agent
credentials, project directories and conversations are preserved.

After deployment, reload an open app to use the new interface. On Mac or iPhone,
open the sidebar and select **MACT** at the top. The session-list refresh button
refreshes only the list. Save unsent drafts before reloading.

# v0.6.22

Completes the official repository transition to **arizzi74/MACT**. New
installations use the MACT release repository by default. The installer,
enrollment instructions, documentation and website links use the new repository;
the public website uses `https://arizzi74.github.io/MACT/`.

Install the v0.6.21 compatibility manager on every enabled gateway and worker
before renaming GitHub. Existing installations that still save the old repository
name continue to follow the authorized redirect with strict asset and provenance
verification. Historical releases retain their original signer; custom repository
selections keep their independent policy. Official installations require v0.6.21
or later, and the bootstrap can recover a manager that missed the bridge.

The `mact` and `codex-telegramgw` commands manage the same installation. Service
names, on-disk paths, release assets, runtime settings, credentials, sessions,
archives, gateway URLs and installed web app identity remain unchanged.

See the [MACT migration guide](../mact-migration.md) for verification and recovery.

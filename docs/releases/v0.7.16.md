# v0.7.16

Resolving a tool approval in the Web UI now deletes its corresponding Telegram
approval cards for both Codex and Claude Code. Cleanup uses the original bot,
chat and message identities, survives sender restarts and retries, and also
handles an approval resolved before its Telegram send finishes. Unanswered
questions and saved question/answer messages remain visible.

Claude permission changes are checked with an isolated native control before
being saved. A mode disabled by native settings or organization policy produces
an explicit error and preserves the existing session settings. If native
startup reports a different permission mode, the turn stops before sending a
model prompt under that mode.

Incomplete Claude accounting shows a known subtotal as **Session ≥$… (partial)**
with an explanation. Missing account allowance data shows **API spend
unavailable** and is retried on the usual usage refresh. Neither figure is
presented as an invented complete cost or account balance.

Validation: full production Go and browser suites, targeted race checks for
approval cleanup and native permission handling, vet, formatting, and full Git
history/current-tree secret scanning.

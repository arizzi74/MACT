# v0.6.34

- Worker observer subscriptions no longer remain permanently unconfirmed after
  cancellation when Codex subsequently returns a valid matching acknowledgment.
  Unresolved subscriptions are deduplicated. Fresh idle checks still protect
  active turns, queues, goals, approvals, and uncertain modifying operations.
- Bounded RPC update diagnostics are included in worker heartbeat runtime
  metadata, without thread identifiers, request parameters, or reply contents.
- Telegram progress moves below a delayed quoted answer echo after its final
  message chunk is delivered. The hourglass remains before the tool card, and
  retries, gateway restarts, completed turns, and unrelated session bindings are
  covered by regression tests.

An older worker already stuck behind an unconfirmed observer subscription needs
one controlled restart after its native runtime is verified idle. Installing the
new source cannot alter the old running process's request bookkeeping.

# v0.7.5

- Support project archive and restoration with Codex 0.165.0 as well as
  0.163.0. Verify each version's native SQLite layout and prove restoration
  using isolated, credential-free native runtimes before removing a project.
  Archives currently require the same Codex version for restoration; attached
  side-thread relationships and unvalidated versions are refused safely.
- Explain unsupported archive and restore versions accurately in the Web UI.
  Failed compatibility checks leave the project and any existing archive intact.
- Configure each Codex worker's default model, reasoning effort, and permission
  level in the Operations console. Defaults apply to new sessions and session
  clears without changing existing sessions.
- Keep newly created, empty Codex sessions visible after worker restarts, and
  prevent answered multiline asynchronous questions from reappearing.

The gateway and workers use the verified release process. Worker restarts wait
until active work and pending requests have finished.

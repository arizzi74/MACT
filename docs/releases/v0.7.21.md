# v0.7.21

Claude Code skills can now be listed and invoked from WebUI and Telegram using
`/skill [name] [arguments]`; `/skills` also opens the list. Discovery uses the
selected session's native Claude command metadata without a model prompt.

The WebUI adds skill search, composer suggestions and an optional argument form.
Telegram provides paged, single-use skill buttons scoped to the original user,
bot and session. Unknown skills are rejected before sending a prompt. Active
sessions queue skill invocations until the current turn and background tasks end.

Focused validation covers native discovery and dispatch, argument preservation,
queued turn ownership, menu origin/replay checks and mobile/desktop browser flows.
Release scope proof, security scanning, signed artifacts and platform packaging
remain required. Unchanged audio inference tests are not run.

# v0.6.14

Fixes optional project cleanup when another idle session uses the project's
parent directory. A session at `~/CODEX` previously prevented archiving and
removing `~/CODEX/Thyros`. Cleanup now treats a directory as shared only when
another independent session uses that directory or one of its subdirectories.
Symlink aliases resolve to the same protected project paths.

Only the selected project subdirectory can be removed. The parent directory
and neighboring projects remain intact. Active work in an ancestor directory,
protected worker paths and genuinely shared project directories still block
unsafe operations.

Tests cover gateway and native inventories, archived records, symlink aliases,
directory boundaries and active ancestors. The real Codex 0.163.0 archive and
restore proof now includes an idle parent-directory session and checks that
the parent inode and files outside the selected project survive cleanup.

# v0.7.23

Fix the Claude skills picker in the WebUI. Skills now use full-width rows with
the name above a muted description, instead of inheriting the narrow numbered
command columns. Long descriptions have a three-line preview; selecting a skill
shows its full description with the optional argument form.

The WebUI shows the full catalog count without Telegram's page indicator. Skill
buttons also keep native keyboard activation. Browser regression checks exercise
112 skills with long names and descriptions at 320, 390, 768 and 1280 pixels,
including row widths, text separation, overflow, search and argument submission.

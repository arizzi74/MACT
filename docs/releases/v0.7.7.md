# v0.7.7

- Automatically check supported native Claude Code installations for runtime
  updates daily, alongside MACT worker maintenance. Explicit worker updates and
  `mact update claude` also check the runtime; `mact update claude --check`
  reports available updates without installing them.
- Follow Claude's configured official release channel, using `latest` by
  default. Respect version bounds and disabled updates. Leave package-manager
  installations, custom launchers, and unsupported managed policies unchanged.
- Verify official Claude release signatures, sizes, and SHA-256 checksums before
  testing candidates in an isolated initialization probe. Apply updates only
  after authoritative idle checks, including background tasks, approvals, and
  queued input. Preserve account configuration and conversation data.
- Recover interrupted runtime upgrades and roll back failed candidates using
  retained private executable backups. Report Claude runtime update results
  independently from MACT worker and Codex runtime updates.
- Clear a transient Codex retry banner when fresh tool activity confirms that
  the turn has resumed. Ignore replayed activity and retain terminal errors until
  the next prompt.

The first upgrade from an older MACT version installs the new updater. Claude
runtime checks then run on subsequent maintenance or an explicit update.

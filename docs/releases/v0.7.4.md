# v0.7.4

- Configure each Codex worker's default model, reasoning effort, and permission
  level from the Operations console. Defaults apply to new sessions and session
  clears, while existing sessions keep their settings. Workers can be configured
  while other sessions are running.
- Keep newly created, empty Codex sessions visible after worker restarts, even
  when Codex omits them from its native session list. Preserve session identity
  and respect explicit archive and deletion state.
- Fix answered asynchronous questions reappearing in the Web UI when their
  titles contain multiple lines or are long. Recognize earlier answer formats
  without resubmitting prompts.

The gateway and workers update through the verified release process. Workers
with active work wait until they are safe to restart. During a staggered update,
the new Codex settings appear when both gateway and worker support them.

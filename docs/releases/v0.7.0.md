# v0.7.0

MACT now manages both Codex and Claude Code through dedicated workers, with a
shared Web UI, operations console, and Telegram bots.

- Install a separate `claude-worker` on Linux or macOS, on amd64 or arm64. Codex
  and Claude workers can coexist on the same account with separate identities,
  services, configuration, session data, and update queues.
- Configure a Claude worker's model, API endpoint, account credential, and
  permission mode from the operations console. Credentials remain private and
  are not included in session history or status reports.
- Create and resume Claude sessions from MACT. New Claude project paths default
  to `~/CLAUDE_CODE/<session_name>`. Existing explicit workspace restrictions are
  preserved. Follow-up messages during a Claude turn queue a successor turn.
- Display Claude's reported context, permission mode, activity, and USD session
  consumption. Supported Abliteration accounts also show remaining credit.
- Delete an idle Claude conversation and its session-specific native and MACT
  worker records while preserving the project directory, shared memory, and
  other conversations. Interrupted deletion can be retried safely.
- Collapse or expand each worker's sessions in the Web UI sidebar. Worker names,
  session counts, and the new-session button remain visible. Preferences are
  remembered; search temporarily reveals matching sessions.
- Simplify the repository README to a short introduction, installation commands,
  and an architecture diagram. Move the detailed overview into `docs/overview.md`
  and update both project websites for Codex and Claude Code support.
- Update the Go networking dependencies, including the HTML parser fix for
  GO-2026-6860.

Claude Code must already be installed and authenticated, or configured with an
appropriate API account. Claude support currently covers sessions created
through MACT; it does not import every pre-existing Claude conversation.
Claude archive/restore, Codex goals and quotas, and local Codex terminal
attachment are not advertised as Claude capabilities.

Gateway and worker updates use the existing verified release mechanism. Worker
updates wait for active work, queued prompts, and pending questions to finish.

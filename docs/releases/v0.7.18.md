# v0.7.18

Claude Code sessions now support `/compact` from the Web UI and Telegram.
Compaction runs in the existing native conversation, preserves session settings,
and remains active until Claude finishes. The Web UI distinguishes completed,
skipped, failed and interrupted compaction, including automatic compaction.
Context usage uses Claude's reported post-compaction size, or is cleared until
Claude reports the new input size.

This release uses a verified compaction-only change scope for focused Go race
tests and desktop/mobile Claude browser checks. Unchanged audio inference and
unrelated feature tests are omitted; complete platform packages, security checks,
release verification and signed provenance remain required.

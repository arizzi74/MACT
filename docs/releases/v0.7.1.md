# v0.7.1

- Keep Claude turns active while background agents or commands are running, and
  until the parent has consolidated their results. Track task snapshots and
  notifications, retain intermediate output, and wait before starting queued
  prompts. Stop also retires the underlying process group.
- Preserve every public text and tool block when Claude emits several blocks
  under one message ID. Preserve final reports delivered in result events and
  record cumulative turn costs without counting them twice.
- Add an explicit, local recovery operation for completed Claude turns whose
  native transcript contains output omitted by an older worker. Recovery checks
  that the session is idle, preserves conversation identity, records native
  timestamps, and invalidates cached history without starting another model
  request. Totals that cannot be reconstructed are marked incomplete.
- Retain terminal session errors in the gateway so model-capacity failures and
  other stopped turns remain visible when switching sessions, reconnecting, or
  reopening the Web UI. A new prompt clears the previous failure. Errors before
  a native turn starts are retained too; transient retry notices still clear
  when work recovers.

Gateway and workers use the existing verified update process. Active work and
pending questions continue to delay worker updates until it is safe to restart.

# v0.7.2

- Fix asynchronous questions reappearing after a Web UI answer when the question
  contains multiple lines or a long title. Send the native quoted-title format,
  including its UTF-8 byte limit, while displaying the complete question.
- Recognize answers already submitted using the older Web UI multiline format.
  Reconcile only exact, preceding questions, preserving multiline answers and
  the boundaries between bundled answers. Recovery does not resubmit prompts.
- Cover multiline shell questions, Unicode and byte-limit boundaries, multiple
  questions, history replay, worker snapshots, and reconnects in browser and
  worker regression tests.

# v0.7.17

Includes the resolved Telegram approval cleanup, native Claude permission
validation, and clearer incomplete-cost/account-spend indicators in v0.7.16.

Claude now publishes an explicit idle thread status when a turn finishes.
A browser that connected during the turn no longer leaves an active snapshot
marker behind after completion, which could indefinitely defer an otherwise
idle worker's update. Pending turns, approvals, queues and background work
continue to block updates through the existing admission checks.

A regression test uses the real gateway, worker, native CLI bridge and browser
relay: connect while approval is pending, approve it, finish a queued successor
turn, then obtain and release the normal worker-update admission lease.
